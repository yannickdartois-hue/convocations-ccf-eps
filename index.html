📂 Import du fichier d'élèves (Pronote)
📋 Instructions pour importer les données depuis Pronote
  1. Dans Pronote, allez dans l'onglet Groupes.
  2. Sélectionnez votre groupe (ex : EPS T-EPS-...).
  3. En haut à droite, cliquez sur Copier dans le presse-papier.
  4. Ouvrez un fichier Excel (XLS) et collez la liste.
  5. Enregistrez ce fichier. C'est celui-ci que vous devez téléverser ici.
